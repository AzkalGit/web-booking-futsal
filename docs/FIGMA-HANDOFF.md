# Garuda Arena — Figma Handoff

## Recommended import
- Viewport: **1440 × 900 px** for desktop captures.
- Keep browser zoom at 100%.
- Import the final HTML screens after local assets are placed.
- Keep mobile captures at 390 × 844 px as the baseline mobile frame.

## Prototype behavior to preserve
- Customer booking data is simulated through `localStorage`.
- Admin approval/rejection changes the same booking record seen by the customer.
- Occupied slots are simulated; this is not live availability data.
